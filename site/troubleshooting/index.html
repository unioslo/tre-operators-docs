Troubleshooting & FAQs

This section helps TRE Operators resolve common issues quickly.

Practical Example: User Access Issue

Problem: Researcher cannot access the TRE workspace. Solution: 1. Check the IAM system for correct user credentials and role assignment. 2. Verify network connectivity and firewall settings. 3. Review audit logs for failed login attempts.

FAQ

  • How do I reset a user's password?
  • Use the IAM system's password reset function and notify the user securely.
  • What if data egress is blocked?
  • Ensure the egress request meets policy requirements and is approved by a Data Steward.
  • How do I monitor system health?
  • Use built-in monitoring tools and review system logs regularly.
